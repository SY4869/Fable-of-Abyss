GraceForsaken の遊び方

4人と4人が6マスの戦場で向かい合うターン制バトルです。誰をどのマスに立たせるかで、届く相手も狙われる相手も変わります。

ゲームを始める

Ⅰはじめかた

1. 名前NAMEタイトル画面の START から、プレイヤー名（12文字まで）を決めます。あとからオプションで変更できます。
2. 最初の4人FIRST PARTY全キャラクターの中から4人を選びます。習得スキルは候補6種からランダムで3種が選ばれます（あとで選び直せます）。
3. チュートリアルTUTORIAL魔人3体との戦闘で操作を確かめます。勝敗にかかわらずメインメニューへ進みます。

進行はブラウザに自動で保存されます。次からはタイトル画面の LOAD で続きから遊べます。

Ⅱパーティと配置

メインメニューの PARTY で、出撃する4人と、それぞれの立ち位置（前衛・中衛・後衛）を決めます。キャラクターをドラッグするか、選んでから「ここへ」を押して動かします。

戦闘の前には戦闘準備の画面があり、敵の編成を見てから配置を変えられます。

射程1のキャラクターは前衛に置かないと攻撃が届きません。打たれ弱い魔法使いは、射程が足りる範囲でなるべく後ろへ。

Ⅲ距離と射程

戦場は左から 自3・自2・自1・敵1・敵2・敵3 の6マスです（1が前衛、3が後衛）。

距離は 自分のマスの番号 + 相手のマスの番号 − 1。この距離が射程以内の相手にだけ、攻撃やスキルが届きます。

射程1RANGE 1自分の前衛 → 敵の前衛だけ
射程2RANGE 2自分の前衛から敵の中衛まで／自分の中衛から敵の前衛まで
射程3RANGE 3自分の後衛から敵の前衛まで、など

どちらかの前衛が全員倒れると、その陣営の残りは1マスずつ前へ押し出されます。前衛が1人しかいないときは、その1人は自分から後ろへ下がれません。

Ⅳ戦闘中の操作

ラウンドごとに、速度の高いキャラクターから行動します。上部の TURN ORDER に行動の順番が出ます。自分のキャラクターの番になったら、画面下のコマンドから選びます。

通常攻撃ATTACK射程内の敵1体を攻撃します。MPを使いません。
スキルSKILLMP（一部はHP）を使って攻撃・回復・強化を行います。1体を狙うもの、1マスをまとめて狙うもの、自分や全体にかかるものがあります。
クイックQUICK行動を消費しないスキルです。使ったあとも同じ手番で続けて行動できます。
移動・待機MOVE / WAIT隣のマスへ1つ動く、または何もせずに手番を終えます（リアルタイム対戦でも待機できます）。

コマンドを押すと、狙える相手やマスが光ります。選ぶと実行、「キャンセル」で選び直せます。自分にかかるスキルは、効果の範囲を確認して「決定」を押します。キャラクターをタップすると、そのキャラクターの状態を確認できます（敵のスキルは見えません）。

カットイン演出はオプションで切れます。テンポよく進めたいときにどうぞ。

状態

戦闘画面上部の「相性・状態」ボタンで、属性相性と状態の一覧をいつでも確認できます。キャラクター情報欄の状態タグをタップすると、その効果の説明が出ます。

洗脳CHARM【チャーム】などで付与されます。攻撃・スキルを使うとき、70%の確率で対象がランダムに変わります（味方を攻撃してしまうことも）。自分の手番の開始時に「魔法防御力×3%」の確率で解除されます。
隠密STEALTH単体攻撃の対象に選ばれなくなります。範囲攻撃・全体攻撃は当たります。一部の固有スキルを持つキャラクターには見破られます。
シールドSHIELD受けるダメージを数値の分だけ肩代わりします。
リーサルカウントLETHAL残りラウンド数が0になると、ラウンド終了時に戦闘不能になります。
アンチヒールANTI HEALHPの回復・蘇生を受けられなくなります。
耐えENDUREHPが0になるダメージを受けたとき、確率でHP1で耐えます（1度発動すると消えます）。
貫通PIERCE相手の防御力を無視してダメージを与えます。【絶対領域】などのダメージ無効化も貫通します。

Ⅴ属性とフィールド

有利な属性で攻撃すると、ダメージが1.5倍になります。

相性ELEMENT火 → 風 → 雷 → 水 → 火（矢印の先に強い）。光と闇は互いに強い。
昼DAY光属性の物理防御力・魔法防御力 +1
夜NIGHT闇属性以外の命中率 −5%。夜に強くなる固有スキルもあります
草原PLAINS風属性の速度・物理防御力 +1
水辺WATERSIDE水属性以外の速度 −2
山脈MOUNTAIN雷属性の速度・魔法防御力 +1
火事場BLAZE火属性の物理攻撃力・魔法攻撃力 +1

Ⅵ仲間を増やす

ストーリーSTORYキャラクターごとに全3話。最終話をクリアすると、そのキャラクターが仲間になります。クリアのたびに Soul がもらえます（初回は多め）。
ガチャGACHA1回 300 Soul、10回 2,700 Soul。未所持のキャラクターが優先して出ます。重複したときは Soul に戻ります。
スキルの選び直しSKILLキャラクター一覧やパーティ編成から、50 Soul で候補6種の中から好きな3種を選び直せます。

Ⅶ対戦

メインメニューの BATTLE から、2種類の対戦を選べます。

ゴースト対戦

他のプレイヤーが設定した防衛パーティ（AI操作）と戦います。30ラウンドで決着がつかないときは、残りHPの割合が多い方の勝ちです。勝利 80 Soul、それ以外 20 Soul。

リアルタイム対戦

マッチングMATCHING「対戦を開始する」で相手を探します。15秒待っても見つからないときは BOT と対戦します。
戦闘準備PLACEMENT60秒以内に配置を確定します。相手の配置は戦闘開始まで見えません。
制限時間TIMERキャラクター1体の行動ごとに30秒。過ぎると自動で行動し、3回続けて時間切れになると敗北です。
報酬REWARD勝利 150／引き分け 100／敗北 50 Soul（BOT戦はゴースト対戦と同じ）。
通信が切れたらRECONNECT30秒以内に戻れば続きから再開できます。ページを開き直した場合も自動で復帰します。

相手には、あなたのプレイヤー名が表示されます。本名など、ご自身を特定できる情報は名前にしないでください。

Ⅷよくある質問

音が鳴りません

ブラウザの決まりにより、画面を一度クリック（タップ）するまで音は鳴りません。オプションで BGM と効果音の音量を変えられます。

別の端末で続きを遊びたい

進行はブラウザごとに保存されるため、別の端末・別のブラウザには引き継がれません。

リアルタイム対戦に接続できません

時間をおいて再度お試しください。対戦サーバーのメンテナンス中は利用できません。ストーリーとゴースト対戦は通信なしで遊べます。
